# arche-design

Public documentation site for the Arche Design System (pronounced AR-kee, from the Greek for "first principle"), the design system behind Curran Leeds' personal brand. 11ty (Eleventy) builds it; Cloudflare (Workers static assets) serves it.

- Curran is a beginner with code. Explain in small steps and define terms the first time they come up.
- This repo is PUBLIC. Never add client names, NDA details, job-search material, private decision IDs, or anything from the gated case studies, in code, comments, copy or commit messages.
- AI-written copy gets Curran's review before it is pushed. Confirm with him before pushing or anything outward-facing.
- Nothing about Arche goes on his portfolio website (curranleeds.com) until he says so. Do not edit `../my-portfolio` from here.
- **Canon is the active mode.** Klarheit, Nøktern, Omtanke and Ethos are frozen: they stay in Figma, in `data-mode` and in the contrast check, but nobody develops them until a real content type needs a second mode and Curran can name who uses it. The modes were set by heritage, not by need, and ten mode and theme sets cost more to check and maintain than one site justifies. Do not add features for the frozen modes.
- The docs have no mode dropdown and the side nav has no Color modes group. Mode pages are reached by direct link, and each has a "View this page in {mode}" button that applies to that page only and saves nothing. Every other page is Canon.
- Components added in 0.6.0: `.link-card` (one card that is one link), `.link--on-brand` (text link on the brand band, reads `interactive/link/on-brand/*`) and `.docs-hero` (the band at the top of every docs page, in the layout above the side nav). The on-brand primary button's Active state is the white fill with a 4px bar in `interactive/button/primary/on-brand/indicator`. `.page-hero` is the portfolio's About hero and stays as it is. Each has a docs page; the CTA band page documents the next-page band (`.docs-next`, in `docs.css`).
- Nav order comes from `src/_data/nav.js` (all groups, in order). It feeds the side nav, the menu, the "Page N of M" line and the "Continue to" band. A new page needs an entry there with a short `description`. Mode pages stay outside the sequence.
- Names: system "Arche Design System", repo and npm package `arche-design`. Modes: Canon (`canon`, default), Klarheit (`klarheit`), Nøktern (`noktern`), Omtanke (`omtanke`), Ethos (`ethos`). Use plain ASCII for code, file names, CSS and token paths; display names may keep the ø.
- Modes change only semantic color roles. Primitives, type, spacing, grid, radius, motion and component anatomy are identical in every mode. Status colors (Alert/Error, Success, Warning) never change by mode. Components read semantic roles, never primitives.
- Swiss Red is `#FF0000` on screen and in digital, and `#DA291C` in print.
- Each mode may carry its own rules and exceptions. Klarheit uses Swiss red as decoration: one red device per page, a rule above the title, or large numerals in stepped flows. Red never appears on form controls, validation, cards or interactive states.
- Ethos uses Greece Blue as its only color, with no accent. Emphasis comes from type weight and size plus the tint panel. Dark keeps the neutral surfaces. Ethos never uses Alert red for decoration.
- Nøktern uses Norway Blue as its main color and Norway Red in one small device, the Cross: a red stripe with a white line on each side, along the top of the blue band that carries it. Red is never on text, form controls, validation, cards or interactive states. Dark uses deep navy surfaces. Alert red stays the same in every mode.
- **Omtanke (Swedish, Generous):** Sweden blue ramp (built from #005293), the Yellow ramp and neutrals. Bands follow the ground (a page can carry more than one): Yellow 500 with Sweden 800 type on a white page; Sweden 800 with Yellow 50 type on the warm (Yellow 50) page. One type color per colored field. Dark uses Sweden 900 and 800 with the yellow band. Selection highlight is Yellow 500. Logo keeps its true colors. ISI sits in a white tray beside dark fields.
- **Canon (default, full palette):** Greece Blue is structure, Sweden Yellow is identity, Norway Red closes the page. Red appears in the logo and as one end mark: a flat 4px rule under the last text column, full column width, once per page, never on text, controls, validation, cards or interactive states. Yellow is a fill with near-black text, plus the selection highlight. Stat numbers sit in the Greece Blue tint panel. Dark uses neutral surfaces. No Sweden Blue.
- Mode token values come from the Figma file "Arche Design System" (Tokens collection, 10 modes) and from nowhere else. Do not invent or adjust a value; if Figma and the code disagree, Figma wins. Modes are in scope: `data-mode` picks the color mode and `data-theme` picks Light or Dark. No attribute means Canon Light. The mode switcher is docs-only and components never read it.
- The fonts, icons and `theme.js` are copied in from the sibling `../my-portfolio` project by `npm run sync`. Do not hand-edit them here. Arche owns its CSS (`src/css/`) and `tokens/figma-tokens.json`; `tokens.css` is generated by `npm run tokens`. The token source is moving to the Arche Design System Figma file; ask before changing the direction of the sync.
- Every CSS custom property starts with `--arche-`. `npm run check` enforces it.
- Docs never hold their own copy of a token value. Foundations pages read `tokens/figma-tokens.json` through `src/_data/tokens.js`.
- Never fabricate metrics, quotes or claims. Demo numbers stay obvious placeholders.
- Norway Red has three jobs and no others: the logo, Canon's end mark and Nøktern's Cross. It is never on text, controls, validation or cards.
- Archivo and Work Sans have no Greek script. Use Latin letters for Greek words.
- Preview: `npm start`. Production build: `npm run build`.
